# 📁 MindMate AI — Project Files Guide

> **MindMate AI V4** is a Hinglish mental health chatbot for Indian students.
> It uses a custom Bi-LSTM model with attention + Groq LLM (Llama 3.3 70B) for smart responses.
> Now available as a **Full-Stack Web Application** with Flask API + SQLite + Premium Dark UI.

---

## 🌐 Web Application (Full-Stack)

| File | Purpose |
|------|---------|
| **`app.py`** | **Flask backend server.** Serves the frontend, exposes `/api/chat`, `/api/session`, and `/api/history` endpoints. Connects `bot_logic.py` to the web UI. Run with `python app.py`. |
| **`bot_logic.py`** | **Modular chatbot engine.** Refactored from `test_bot.py` for server use. Exposes `generate_reply(session_id, message)` function that handles classification, response generation, and DB logging per session. |
| **`database.py`** | **SQLite database layer.** Manages `users` and `chat_history` tables in `mindmate.db`. Handles session creation, message saving, and history retrieval. |
| **`requirements.txt`** | Python dependencies: `flask`, `flask-cors`, `tensorflow`, `numpy`, `groq`. |

### 🎨 Frontend

| File | Purpose |
|------|---------|
| **`templates/index.html`** | **Main UI.** Welcome modal, chat interface, emergency modal. Uses Ionicons + Google Fonts (Inter/Outfit). |
| **`static/style.css`** | **Premium CSS.** Glassmorphism panels, animated neon orbs, gradient chat bubbles, dark cosmic theme. |
| **`static/script.js`** | **Frontend logic.** Session management (localStorage), API communication (fetch), typing indicators, message rendering, smooth animations. |

## 🧠 Core Bot Files (Terminal Version)

| File | Purpose |
|------|---------|
| **`test_bot.py`** | **Original terminal chatbot.** Run this for CLI mode. Contains the full classification pipeline, risk analysis, response engine, Groq API integration, and conversation loop. |
| **`responses.json`** | **Response database.** All static responses organized by emotion (happy, sad, critical, abuse, grief, out_of_context) with validation messages, followups, advice, entertainment, and helplines. |

## 🏋️ Training Pipeline

| File | Purpose |
|------|---------|
| **`train_model.py`** | **V3 training script.** Builds and trains the Attention-Enhanced Bi-LSTM on `AUGMENTED_dataset.csv`. Outputs `mental_health_model.h5`, `tokenizer.pickle`, and `model_config.pickle`. |
| **`train_model_v4.py`** | **V4 enhanced training.** Merges original + AI-generated data, optional GloVe pre-trained embeddings (100d), label smoothing, smarter architecture. |
| **`generate_ai_data.py`** | **AI data generator.** Uses Groq API (Llama 3.3 70B) to generate diverse Hinglish training examples for each class, including edge cases like negated sentiments and misspellings. Outputs `AI_GENERATED_dataset.csv`. |
| **`augment_dataset.py`** | **Dataset augmentation.** Takes `UPDATEDdataset.csv`, injects failure phrases, adds chitchat class (label=4), generates synonym variations, and outputs `AUGMENTED_dataset.csv`. |

---

## 📊 Datasets

| File | Purpose |
|------|---------|
| **`UPDATEDdataset.csv`** | **Base dataset** (~6K+ rows). Contains text samples labeled 0-3 (Happy, Sad, Critical, OOC). Input for `augment_dataset.py`. |
| **`AUGMENTED_dataset.csv`** | **Final training dataset** (~8.4K rows, 5 classes 0-4 including chitchat). Generated by `augment_dataset.py`. Used by `train_model.py`. |
| **`AI_GENERATED_dataset.csv`** | **AI-generated supplement** (generated by `generate_ai_data.py`). Extra diverse examples for each class, especially negated phrases and edge cases. |

## 🚀 How to Run

```bash
# Start the web application (recommended)
pip install -r requirements.txt
python app.py
# Open http://127.0.0.1:5000 in your browser

# Start the terminal chatbot (standalone)
python test_bot.py

# Retrain the model (V4 with AI data + GloVe)
python generate_ai_data.py       # Generate AI training data
python train_model_v4.py         # Train with merged data + GloVe

# Retrain the model (V3 traditional)
python augment_dataset.py
python train_model.py

# Run tests
python run_comprehensive_test.py
python verify_model.py
```
